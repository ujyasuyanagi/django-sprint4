# Blogicum

«Блогикум» — учебный проект блога на Django (Яндекс Практикум, финальный
проект спринта). Финальная версия: пользователи, профили, публикации с
изображениями, комментарии, пагинация и кастомные страницы ошибок.

## Возможности

- Модели `Post`, `Category`, `Location`, `Comment` с общим абстрактным
  базовым классом для публикуемых объектов.
- Админ-зона на русском языке для управления публикациями, категориями,
  местоположениями и комментариями.
- Пользователи: регистрация (`/auth/registration/`), вход и выход,
  смена пароля, восстановление пароля через письмо.
- Страница пользователя `/profile/<username>/`: информация о нём, его
  публикации, счётчики комментариев; владельцу доступны ссылки на
  редактирование профиля и смену пароля.
- Публикации: создание `/posts/create/`, редактирование
  `/posts/<post_id>/edit/`, удаление `/posts/<post_id>/delete/`
  (только автор), изображение к посту, отложенные публикации.
- Комментарии: добавление `/posts/<post_id>/comment/`, редактирование
  `/posts/<post_id>/edit_comment/<comment_id>/`, удаление
  `/posts/<post_id>/delete_comment/<comment_id>/` (только автор);
  сортировка «от старых к новым», количество комментариев в карточках.
- Пагинация: не более 10 публикаций на главной странице, на странице
  пользователя и на странице категории.
- Статичные страницы «О проекте» и «Правила» реализованы CBV.
- Кастомные страницы ошибок: 403 CSRF, 404, 500.
- Отправленные письма складываются в директорию `sent_emails/`
  (файловый бэкенд почты, директория исключена из репозитория).

## Установка и запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cd blogicum
python manage.py migrate
python manage.py loaddata ../db.json   # наполнение базы, по желанию
python manage.py runserver
```

Сайт доступен по адресу http://127.0.0.1:8000/, админ-зона —
http://127.0.0.1:8000/admin/.

## Тесты
